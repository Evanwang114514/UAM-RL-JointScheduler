确认没有他人重占GPU/CPU后执行下面三条。资源状态未知，AI没有替你标记“可安全开跑”。只显示一张GPU时用0；若已有训练运行，目录锁会阻止同一矩阵重复启动。

```bash
mkdir -p /home/SY/wyw/logs
nohup env CUDA_VISIBLE_DEVICES=0 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 /home/SY/wyw/conda/envs/uam_server/bin/python -B -u /home/SY/uam/UAGMC-main/train_uam_space_time_14h_ONEFILE.py --resume --device cuda --wall-hours 14 >> /home/SY/wyw/logs/uam_space_time14h_20261104.log 2>&1 < /dev/null &
echo "普通训练PID：$!"
nohup env CUDA_VISIBLE_DEVICES=0 XLA_PYTHON_CLIENT_PREALLOCATE=false XLA_PYTHON_CLIENT_MEM_FRACTION=.45 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 /home/SY/uam/UAGMC-main/workspace/envs/uam_dv3_20261104/bin/python -B -u /home/SY/uam/UAGMC-main/train_uam_hot_transfer_40h_ONEFILE.py --resume --device cuda --wall-hours 40 --ppo-python /home/SY/wyw/conda/envs/uam_server/bin/python --harl-dir /home/SY/uam/UAGMC-main/workspace/vendor/HARL >> /home/SY/wyw/logs/uam_hot_transfer40h_20261104.log 2>&1 < /dev/null &
echo "热点迁移PID：$!"
nohup env OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 /home/SY/wyw/conda/envs/uam_server/bin/python -B -u /home/SY/uam/UAGMC-main/diagnose_uam_threeway_comprehensive_ONEFILE.py --resume --workers 2 --states 12 --follow-new --follow-hours 54 >> /home/SY/wyw/logs/uam_threeway_diag_20261104.log 2>&1 < /dev/null &
echo "综合诊断PID：$!"
```

诊断从服务器既有76.7M和60M目录只读加载固定最终模型。旧76.7M模型不全会明确报错；60M缺项保留在清单，不挑Best替代。两组训练在内部逐格运行；只有矩阵之间并行。退出续跑用相同命令，已完成cell不重新训练；不要同时启动第二个相同父进程。

## 5．服务器Linux：完成后自动打包，核对文件

```bash

ls -lh experiment_archives/uam_space_time_16run_48m_v1_*tar.gz
ls -lh experiment_archives/uam_hot_transfer_16run_40h_v1_*tar.gz

cat workspace/artifacts/uam_threeway_diagnostics_20261104_v1/END.json
```

这些是脚本完成或正常PARTIAL收尾时将创建的名字，**不是现在已存在的远程文件**。DATAONLY保留任务、配置、hash、日志、评估和错误，不含模型；FINAL_REPLAY_MODELS保留模型／归一化及阶段存档，体积会更大。Dreamer的完整Replay训练缓冲不进下载包，仍留服务器供继续训练；下载模型能冻结评估，但不等于下载了离线训练全集。

不要对仍在写的矩阵目录手动整体tar。异常退出未打包时先看失败日志并续跑，让入口按一致协议收尾。
