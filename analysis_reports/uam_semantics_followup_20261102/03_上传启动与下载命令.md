# 六千万正式训练：上传、启动、续跑、打包、下载

代码：`train_uam_stage_credit_18h_ONEFILE.py`。文件名保留18h表示会话上限；实际已改成24格、58,490,880计划步、60,000,000工作硬上限，含STIN开关消融。无需上传其他矩阵入口或模型包，所有模型从头训练。

以下路径沿用用户本轮持续使用的目录，不代连服务器。Windows和Linux命令分开粘贴，不要把`cd /d`、`%变量%`或`>nul`粘进Linux终端。


## 2．登录后的Linux服务器：查看共享资源，然后直接正式启动

```bash
cd /home/SY/uam/UAGMC-main
top -b -n 1 | head -n 20
nvidia-smi
```

确认0号GPU及CPU没有被其他人重度占用后，运行下面这段。只有一套训练，不要重复启动多个父进程。

```bash
mkdir -p /home/SY/wyw/logs
nohup env CUDA_VISIBLE_DEVICES=0 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 /home/SY/wyw/conda/envs/uam_server/bin/python -B -u /home/SY/uam/UAGMC-main/train_uam_stage_credit_18h_ONEFILE.py --resume --retry-failed --device cuda --eval-device cpu --wall-hours 18 >> /home/SY/wyw/logs/uam_stage_stin60m.log 2>&1 < /dev/null &
echo "启动PID：$!"
```

预计约14–16小时，但共享负载和STIN实际吞吐尚可能改变时长。18小时到期或预算不足则保留PARTIAL及恢复件，不把它当完成。提前完成不凑时间；不另外设smoke阶段。若GPU忙，先不要启动，不关闭别人进程。

## 3．服务器完成后打包

脚本正常完成会自动生成下面两个包。若只需重新打包，确认没有同一矩阵父进程后执行：

```bash
cd /home/SY/uam/UAGMC-main
/home/SY/wyw/conda/envs/uam_server/bin/python -B -u /home/SY/uam/UAGMC-main/train_uam_stage_credit_18h_ONEFILE.py --resume --phase pack
ls -lh experiment_archives/uam_stage_stin_24run_60m_v1_DATAONLY.tar.gz experiment_archives/uam_stage_stin_24run_60m_v1_FINAL_REPLAY_MODELS.tar.gz
sha256sum experiment_archives/uam_stage_stin_24run_60m_v1_DATAONLY.tar.gz experiment_archives/uam_stage_stin_24run_60m_v1_FINAL_REPLAY_MODELS.tar.gz
```

DATAONLY包含合同、配置、逐模型结果、曲线、反馈误差、逐选择分支和错误日志，不含模型。FINAL_REPLAY_MODELS包含最终模型及配套归一化，只有全部模型评估完成才生成；不能把PARTIAL包当完整模型包。

## 4．另开本地Windows CMD下载到项目

```cmd
cd /d "E:\Study Files\github\UAM-predict\UAGMC-main"
if not exist "experiment_archives" mkdir "experiment_archives"
scp -O -P 10111 SY@22.tcp.vip.cpolar.cn:/home/SY/uam/UAGMC-main/experiment_archives/uam_stage_stin_24run_60m_v1_DATAONLY.tar.gz "experiment_archives\uam_stage_stin_24run_60m_v1_DATAONLY.tar.gz"
scp -O -P 10111 SY@22.tcp.vip.cpolar.cn:/home/SY/uam/UAGMC-main/experiment_archives/uam_stage_stin_24run_60m_v1_FINAL_REPLAY_MODELS.tar.gz "experiment_archives\uam_stage_stin_24run_60m_v1_FINAL_REPLAY_MODELS.tar.gz"
tar -tzf "experiment_archives\uam_stage_stin_24run_60m_v1_DATAONLY.tar.gz" >nul && echo 数据包可读取
tar -tzf "experiment_archives\uam_stage_stin_24run_60m_v1_FINAL_REPLAY_MODELS.tar.gz" >nul && echo 模型包可读取
certutil -hashfile "experiment_archives\uam_stage_stin_24run_60m_v1_DATAONLY.tar.gz" SHA256
certutil -hashfile "experiment_archives\uam_stage_stin_24run_60m_v1_FINAL_REPLAY_MODELS.tar.gz" SHA256
```

核对本地与服务器SHA一致后，再把包发来分析。不要在Linux上执行本节Windows命令。
