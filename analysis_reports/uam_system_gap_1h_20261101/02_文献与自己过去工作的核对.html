检索过程与失败也保留

按paper-search流程尝试本地多源检索入口，但在导入时失败：

ModuleNotFoundError: No module named 'requests'

没有安装包或修改用户环境。随后使用联网检索和原始页面定向核对；arXiv正文/摘要、出版商摘要和作者SSRN页是本轮来源。不能把这次称为六个学术API均成功检索，也不构成完整全球新颖性检索。全文访问失败的记录如实标注。

未纳入设计依据的噪声结果包括飞行控制器、事故风险和学位论文；本轮不据它们作交通调度结论。没有为了凑篇数把非匹配任务列为直接支持。

实验设计技能只用于配对、分层、统计单位和失败保留等流程，不是UAM科学证据。相关工具方法来源：Kassis等，Scientific Agent Skills，2026，原始记录。

本轮保留什么、不做什么

保留：同状态合法分支、原动作复现、共同后续策略、完整回放验证、强规则公平对照、人时分解。

暂不做：新加充电约束/天气/机队配置，搜索座位数或机场位置，盲加WM/MARL、扩散/Flow或新PPO参数。不否认这些方向存在价值，只是本轮没有相应证据和预算。

如果结果支持候机协调损失，也只能进入“具体机制与最近邻文献排查”，不能直接写“别人都没解决”。强READY与作者QTTI也不是数学最优，更不代表所有现代滚动优化已经被击败。
