# 两组结果与下一步：先读这一页

2026-11-02。四份正式报告＋两份单文件实验入口。报告状态：已分析；新实验状态：已设计、未运行。

## 最重要的结论

1. 新增时间/凑批信息没有证明稳定增益，联合双信息的平均改善受一个差基座种子明显影响。
2. 普通Transformer与双信息LSTM接近；当前不能写“普通PPO＋Transformer无法解决”。
3. 后期未完成场次中，871/877在截止时只剩各站不足4人的队列、飞机空闲。不能把它们统一叫联合死锁。
4. 给强规则同样的事后尾批处理后，学习模型仍有差距；但强READY三站的有限整场交换未找到进一步改善，普遍交通缺口尚未立住。
5. 候选好坏随评价窗口和后续新请求而变化。下一轮先用最新模型复诊，再公平检验普通网络的折扣范围，不先加WM/MARL。

## 只需记住这些词

| 词 | 人话与单位 |
| --- | --- |
| RPT | 截止前所有已出现乘客累计耗时÷人数，分钟/人；不是最终全员ATT |
| ATT | 所有人完成后的平均旅时；未全完成时空值，不补0 |
| Single/LQ | 乘客学习选站，飞机按最长队规则 |
| Joint/J3 | 乘客与飞机都由该策略实现控制；不是HAPPO等算法认证 |
| seed | 一次独立训练的随机种子；一模型多次回放不增加训练样本数 |
| TIME/BATCH | 合法时间描述／四座人数余数；后者不是优化器batch_size |
| L00/L10/L01/L11/T11 | 不新增／只时间／只余数／两者都给LSTM／两者都给普通Transformer |
| gamma | 折扣因子：较远成本相对现在成本的权重；不是新交通奖励项 |
| BASE/READY后续 | 当前动作之后继续原策略／统一用强规则；当前动作仍按原控制接口执行 |
| COMMITTED | 这里特指删除未出现请求的近似分支，不是完整合法需求预测器 |
| REALIZED/Oracle | 真实后续请求继续出现的事后诊断；不允许输入在线策略 |
| 人分钟 | 局部总成本单位，不是分钟/人；窗口重叠的收益不可相加 |
| WM/MARL | 世界模型／多智能体强化学习；本轮不开发这类新方法 |

分层：评估行嵌套于存档、请求顺序和训练模型；主要独立单位是训练种子。诊断状态也嵌套在策略和顺序内。缺失ATT代表删失，不是零。`final_area_before/after_300`只来自最终模型完整分钟记录，不与缺失中间轨迹混算。图的横轴是存档标签；例如1000000存档和1003520最终存档的更新次数分别480/490，不是完全相同的两个模型；训练预算以TRAIN_END的实际transitions计。

## 方法与完整性说明

使用academic-research-suite做分析/设计结构核对；实验设计、统计分析、EDA与科学绘图流程用于正确的配对、分层、缺失处理及真实曲线显示。现有Python3.11环境的NumPy2.4.6、pandas3.0.5、SciPy1.17.1、Matplotlib3.11.1完成只读统计；没有安装技能示例所列的其他运行环境。

程序化数据能力检查和有界CSV概况保存在evidence；没有删异常点、挑坏状态或对确认顺序作全新测试声明。四训练种子的区间和探索检验功效有限，不给出“已证明等价”或伪造事前功效计算。

11/11类误读已检查：

1. 不把单侧、联合与不同K混合，避免总体趋势掩盖分组反转。
2. 不由均值推每名乘客的收益。
3. 诊断抽样按既定早中晚位置，不只选失败状态。
4. 完成率可能受方法影响，不以只完成者筛选作主排名。
5. 所有比例给出状态/回放/种子分母。
6. 不把基座极差种子上的重测改善直接当普适机制；报告留一种子敏感性。
7. 未完成者保留，ATT空值不丢弃；RPT与完成率并列。
8. 所有方法和因子对比均保留，14项探索对比统一校正。
9. 这是看完数据后的探索分析；下一轮新种子对照才承担确认角色。
10. 事后搜索、局部窗口与不同后续策略不冒充单因素因果贡献率。
11. 时间顺序与反事实通过克隆核验，但分组相关性不写成唯一机制。
