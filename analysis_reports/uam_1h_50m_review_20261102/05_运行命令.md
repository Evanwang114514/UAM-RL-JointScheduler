# 上传、启动、结果下载

两份入口均已写入本地项目。以下沿用本轮确认过的路径：Windows `E:\Study Files\github\UAM-predict\UAGMC-main`；服务器 `/home/SY/uam/UAGMC-main`。不是实时登录核验；如你实际已迁移项目，应统一替换路径。Windows CMD和服务器Linux分开粘贴，不能混用。

## 1．本地Windows CMD上传

```cmd
cd /d "E:\Study Files\github\UAM-predict\UAGMC-main"
scp -O -P 10111 "diagnose_uam_50m_credit_1h_ONEFILE.py" "train_uam_credit_horizon_18h_ONEFILE.py" SY@22.tcp.vip.cpolar.cn:/home/SY/uam/UAGMC-main/
ssh -p 10111 SY@22.tcp.vip.cpolar.cn
```

## 2．服务器Linux：先跑约一小时的无训练诊断

按共享服务器要求，先看下面两项，确认没有别人重度使用再启动。无需另跑smoke。

```bash
cd /home/SY/uam/UAGMC-main
top -b -n 1
nvidia-smi
mkdir -p /home/SY/wyw/logs
nohup env OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 /home/SY/wyw/conda/envs/uam_server/bin/python -B -u /home/SY/uam/UAGMC-main/diagnose_uam_50m_credit_1h_ONEFILE.py --source /home/SY/uam/UAGMC-main/serial_runs/uam_gap_factors_48run_50m_v1 --out /home/SY/uam/UAGMC-main/workspace/artifacts/uam_50m_credit_diag_1h_20261102_v1 --wall-seconds 3600 --workers 2 --resume --retry-failed >> /home/SY/wyw/logs/uam_50m_credit_diag_1h.log 2>&1 < /dev/null &
echo "诊断PID：$!"
```

读取进度：

```bash
tail -n 25 /home/SY/wyw/logs/uam_50m_credit_diag_1h.log
cat /home/SY/uam/UAGMC-main/workspace/artifacts/uam_50m_credit_diag_1h_20261102_v1/progress.json
```

## 3．服务器Linux：再启动18小时训练

建议诊断完成后先看`SESSION_END.json`、`TRAINING_ADVICE.json`和两份CSV。如果诊断否定了正常阶段的研究空间，可以暂不启动；下面不会自动跟随诊断运行。**这轮训练是普通基线的目标范围校准，不是新方法擂台。**

```bash
cd /home/SY/uam/UAGMC-main
top -b -n 1
nvidia-smi
nohup env CUDA_VISIBLE_DEVICES=0 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 /home/SY/wyw/conda/envs/uam_server/bin/python -B -u /home/SY/uam/UAGMC-main/train_uam_credit_horizon_18h_ONEFILE.py --resume --retry-failed --device cuda --eval-device cpu --wall-hours 18 >> /home/SY/wyw/logs/uam_credit_horizon18h.log 2>&1 < /dev/null &
echo "训练PID：$!"
```

```bash
tail -n 25 /home/SY/wyw/logs/uam_credit_horizon18h.log
cat /home/SY/uam/UAGMC-main/serial_runs/uam_credit_horizon_32run_18h_v1/progress.json
cat /home/SY/uam/UAGMC-main/serial_runs/uam_credit_horizon_32run_18h_v1/RUNNING.json
```

重复启动同一实验会被父进程锁拒绝；不要开两个相同入口。训练中断或时间预算结束后，同代码同命令`--resume`可续跑，这是新的一次会话预算。创建自己实验目录里的`STOP_REQUESTED`可请求停止；不要对共享账号执行pkill/killall。

## 4．完成后服务器自动打包；需要时补打训练包

诊断正常结束或预算截止会自动在本轮输出目录打DATAONLY包。训练会自动在`experiment_archives`生成DATAONLY；全部32格完整完成后另生成最终模型＋归一化包。

若需要在训练退出后重新打包已有结果：

```bash
cd /home/SY/uam/UAGMC-main
/home/SY/wyw/conda/envs/uam_server/bin/python -B -u /home/SY/uam/UAGMC-main/train_uam_credit_horizon_18h_ONEFILE.py --phase pack --resume
```

这条只压已有记录，不训练。PARTIAL包不冒充完整结果，未全完成时不会声称已有全套最终回放模型。
