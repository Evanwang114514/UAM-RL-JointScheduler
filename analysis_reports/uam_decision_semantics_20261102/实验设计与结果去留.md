## 一句话目的

检查是否存在**普通模型和强在线规则都反复出现的具体选择错误**，把错误落实到可行候选、受影响的人和生效过程。没有这种证据，就不预设下一轮要训练什么。

“分流和调机影响未来服务机会”只是系统目标，不是本论文主观点；PPO已经优化长期回报。本轮不声称PPO/Transformer原理上学不会，不把补信息后涨分当贡献，不为结果改变物理、奖励、机场、座位或机队。

## 一、三个主要角度和一个必要补充

### A．决策时机和动作的时间含义

不是再给网络加ETA，而是记录：当前乘客是否有决策机会、飞机何时真正有多个合法目标、prepare前和dispatch时的可执行集合、指令造成哪架飞机返航、何时到达、何时空闲可服务、何时真正载客。

源码里J3的飞机动作是**这个分钟的目标优先级**，不是长期预约、不是可任意提前起飞的预布置指令；当前队列、可用飞机和source调度规则仍限制执行。许多分钟只有一个合法占位动作，这些不能算模型做对/做错了飞机选择。

补一个单列压力测试：在有真实多目标机会的抽样状态，把本次优先级最多保持3分钟，后续仅在合法时使用。它改变了刷新/绑定契约，**不是公平方法排行榜，也不是新AI收益**。若它影响很大，下一步先查契约；若很小，则降低这一角度优先级。

观测粒度是一分钟，可能跳过同分钟内中间态。缺失就绪/服务时刻标为未观测或删失，不能补造精确时间。一次决策耗时长也不等于决策差，必须结合候选成本。

### B．预测式调度是否有可行动的价值

分开看三件事：

1. 在真实未来的事后回放里，换一个当前合法动作，能否降低到601分钟统一截止的人时？这只证明条件性的事后空间。
2. 不读未来文件，仅用已经出现的OD联合样本、最近60分钟到达数和公开的生成截止，经验重采样4个需求世界。每个动作先跨世界求平均成本，再选动作，不能每个世界各挑赢家后平均。
3. 将这个合法预测选出的动作放回真实未来分支，看120分钟和全程后缀是否更好；同时检查前两次/后两次抽样是否选择一致。

预测不使用删除未来请求的COMMITTED近似、不拟合新网络。它只是一个可复核的朴素合法预测器，失败不能证明所有预测方法无效。事后Oracle成功、合法预测失败也不能直接支持几千万步训练。

只枚举当前接口允许的动作；不能用提前空飞、HOLD、半座起飞、未来请求真值等额外权限制造空间。预测模型若建议现有接口不能做的事情，本轮只能报告控制范围限制。

### C．逐次选择质量，而不是只看整场平均时间

核心量为：**实际选择的人时成本－同状态合法候选中最低的人时成本**。指定后续策略和截止之后，这个量才有含义，不是全局最优regret。

- 看平均损失、90分位损失、近似最优比例。默认2人·分钟容差只用于描述，原始连续值全部保留，不能看结果后改阈值制造胜利。候选本来就几乎等价的状态单列，另报真正有代价差的状态中的近似最优比例，避免用大量无关紧要的选择抬高正确率。
- 把差额分成当前乘客、其他已出现乘客、之后出现乘客；群体在分支开始时固定，保留有利/不利的正负差。
- 同时分成地面、等待、飞行和其他状态占用；两种分解各自严格加和等于总人时，不能把仅完成者时间反推给全体。
- 保存1/5/15/30/60/120/240分钟与整场成本，检查哪一段开始出现代价，短窗口和全程的最优动作集合是否冲突。
- 分开限制只改乘客、只改飞机、同时改；同时改比最好单改额外减少多少只能叫这个状态下的条件交互，不能解释成“MARL贡献百分比”。当原飞机指令在另一个乘客动作后不再合法时，单侧对照集合受限，必须保留这一事实。

只看一条trace、静态比较队列、用网络critic给自己评分，都不能替代实际分支；也不能把不同状态的重叠收益相加，声称解释了整场ATT差距。

### D．避免把模型遇到的不同局面当成能力差异

两套状态分开报告：

- 自己的轨迹：模型平时到底犯什么错？使用原模型与共同READY两种后续规则分别评分。
- 相同READY轨迹：所有模型面对完全相同的物理状态，比较它们的第一次选择；随后统一READY。物理状态hash必须跨模型一致，不一致则拒绝排名。

这里“后续相同”是规则相同，状态变化后动作仍正常响应，不是把另一条世界的固定动作序列硬套过来。READY是项目手写合法强规则，不是数学最优，也不自动代表所有运营研究算法。

## 二、固定规模、输入和运行顺序

- 基准：γ=.99的16模型＋1个READY，4303/4304两条顺序，34条原样回放。必须与各模型原最终记录匹配；γ=1已有上一轮完整分析，本轮不重复占预算。
- 深诊断：固定普通Transformer的8模型（单侧/联合×4种子）＋READY，选择不依赖本轮表现。LSTM只做基准与事件链，不铺深分支。这是30分钟的有意收缩，不能泛化成所有网络结论。
- 每条自己的轨迹抽4个前中期决策，共72个状态；范围为请求索引25–74、100–149、175–224、225–239。避免围绕最后几个零星乘客挑样本，但分支仍保留真实尾部，收益与截止未完成人数一起报告。
- 8模型各在共同READY轨迹的两个位置评分，两条顺序共32个共同状态。
- 自己轨迹中固定两个位置做预测，共36个状态，每个4个合法需求世界，120分钟预测选动作，再用真实全程分支评价。
- 联合每状态至多9个当前候选，单侧/READY为3个。先基准，再按训练seed轮转深诊断，保证不是把某一类控制留到预算末尾。
- 会话上限默认1800秒，最多两个单线程CPU worker；不足写BUDGET_PARTIAL，完整单元保留，同代码--resume续跑。若提前完成就结束，不空转凑30分钟；若共享负载较高也不冒称跑全。不能用训练FPS直接估算诊断耗时，以COUNTERS为准。

4303/4304已经在前轮训练分析里查看过，是验证顺序，不是未见测试。它们仅保留原OD联合多重集、到达时刻下的重排，不证明新需求分布泛化。训练seed才是独立训练单位；分支和回放都是嵌套观测；READY只有一个控制器。

原18小时结果的人时是名义600分钟、实际601个源分钟的积分。本轮强制相同的601边界。未完成时全体ATT仍不能定义，固定截止人时和未完成数另列。另记“已确认全机IDLE、剩余人全在不足4人的队列、需求已结束”的吸收尾部积分，判断收益是否主要靠这部分；它是记账分解，不是新的主指标或独立因果比例。不会删人、改满载规则、自动提前结束原物理。

## 三、什么结果才值得下一步训练

| 本轮结果 | 后续处理 |
|---|---|
| 只有弱模型损失大，强普通Transformer和READY很小 | 不宣称共同交通缺口；先解决有限预算普通学习接近强规则的问题 |
| 多个普通模型及READY均有重复的正常阶段候选收益 | 先把预先选定的稀疏合法替换接回在线整场，确认多次修改没有相互抵消，再考虑具体训练 |
| 事后未来能选好，合法预测不能选好或抽样不稳 | 需求可预测性尚未站住；先验证预测误差/蒙特卡洛精度，不直接上WM或大训练 |
| 合法预测能在READY及多个模型上重复救回损失 | 下一轮先做固定计算预算的在线滚动整场回放，并加入普通PPO/Transformer同信息对照；学习是否必要仍待判断 |
| 新建议大多超出当前可执行集合 | 单列控制接口边界；若修改接口，全部基线同权限重评，不算AI创新 |
| 持有优先级压力测试影响大 | 只能支持继续查刷新/绑定语义，不能直接把契约变化写成时间网络贡献 |
| 收益主要来自截止未完成尾批 | 作为删失/尾部敏感性；不转成座位或尾批处理主线 |
| 参考克隆、配套模型、共同状态hash任一失败 | 这是诊断实现问题，禁止把标签用于训练；修复后保留版本审计 |

最低训练依据不是“局部存在好动作”，而是：**可重复错误＋明确、可部署的改正途径＋整场收益确认＋普通基线不能已在同合同下轻易消除**。本轮尚不替代最后一项整场多次干预验证，也不自动批准训练。

## 四、输出怎么看

1. `05_逐模型摘要.csv`：先看平均选择损失和严重错误，按模型而非几千状态汇总。
2. `02_逐选择质量.csv`：具体哪次选择、影响谁、何时出现；自己的状态与共同状态分开。
3. `03_合法预测与事后空间.csv`：合法抽样建议回到真实未来到底有没有收益，不只看Oracle。
4. `04_决策机会与执行契约.csv`：每分钟是否有选择权，prepare前后是否合法集合变化。
5. `jobs/.../own_BASE.json`：逐分钟占用、逐乘客/逐飞机事件链；`state_*.json`含全部候选和对照，不只保存赢家。
6. `统计与完整性边界.json`、`后续训练去留条件.json`、`SESSION_END.json`：完整性、解释边界、下一步条件。

脚本自动打包DATAONLY，包含自身入口、配置、原始派生记录和日志，不重复打包模型。输入模型和归一化前后hash核验，禁止learn/train/optimizer.step，并冻结归一化统计。失败的单元隔离保留，不中断其他模型；续跑需显式--retry-failed，不删除旧失败文件。

## 五、已有证据与方法边界

本轮依据项目2026-11-02两份分析和下一轮无训练设计收缩，不重新宣称时间通道缺失是主瓶颈。前轮已经看到：局部窗口收益不等于整场收益，普通Transformer尚未被排除，简单补信息没有稳定增益；这些负结果保留。

动作价值比较和保持另一侧条件的反事实比较都有成熟基础，不是本轮创新：[PPO](https://arxiv.org/abs/1707.06347)、[COMA](https://arxiv.org/abs/1705.08926)。[UAGMC](https://arxiv.org/abs/2601.21316)用于界定源任务和源方法，不把本文实验口径与原论文ATT数值混比。

设计技能在本轮的作用是固定问题、状态抽样、反事实条件和去留规则，避免观察到分数后重命名假说。没有新科学结果，也没有连接服务器。
