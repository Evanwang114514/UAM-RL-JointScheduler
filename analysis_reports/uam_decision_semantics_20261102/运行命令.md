## 2．服务器Linux启动


确认后直接正式运行，不设独立smoke阶段：

```bash

nohup env OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 /home/SY/wyw/conda/envs/uam_server/bin/python -B -u /home/SY/uam/UAGMC-main/diagnose_uam_decision_semantics_notrain_ONEFILE.py --wall-seconds 1800 --workers 2 --resume --retry-failed >> /home/SY/wyw/logs/uam_decision_semantics30m.log 2>&1 < /dev/null &
```

